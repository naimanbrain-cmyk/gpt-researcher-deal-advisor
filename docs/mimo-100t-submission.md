# MiMo 100T Submission Draft

## Project Name

Deal Advisor Intelligence Engine — GPT-Researcher Fork for Autonomous Deal Diligence

## Short Description

A MiMo-compatible multi-agent research engine that transforms a company/startup investment question into a full investment memo with market analysis, competitive mapping, risk scoring, and evidence-backed recommendation.

## 1200-character Application Description

I am building a MiMo-powered multi-agent Deal Advisor Intelligence Engine forked from GPT-Researcher. The system converts a business or startup investment question into an autonomous diligence workflow: research planning, web retrieval, source evaluation, market sizing, competitor mapping, product and team analysis, financial/risk scoring, memo writing, review, and publishing. The output is an investment-grade deal memo with a scorecard, confidence estimates, cited evidence, risks, and a clear recommendation. The architecture is designed for high-token, long-horizon research workloads where agents repeatedly search, summarize, critique, and revise. A deep run can consume 12M–20M tokens across planner, researcher, analyst, scorer, reviewer, and writer loops. MiMo will be configured through OpenAI-compatible endpoints so I can compare MiMo with GPT, Claude, and DeepSeek on real autonomous research tasks. I will publish a reproducible GitHub fork with demo tasks, sample memos, architecture docs, and token usage notes.
